ℹ️ Como Funciona?

Cifra de Substituição

Este exemplo usa uma cifra de substituição simples onde cada caractere é substituído por um símbolo único e consistente.

Chave de Criptografia

A chave é gerada automaticamente e mantém a correspondência entre caracteres e símbolos. A mesma chave é usada para criptografar e descriptografar.

Segurança

⚠️ Este é apenas um demonstrativo educativo. A criptografia real para dados sensíveis requer algoritmos muito mais complexos como AES, RSA, etc.
